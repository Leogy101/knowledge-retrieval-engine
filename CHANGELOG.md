# Changelog

## 0.3.2a1 — first public-alpha candidate

This candidate packages the existing independently useful KRE implementation
without publishing its private development history. Version 0.3.2a1 preserves
existing package metadata and planned tag `v0.3.2a1`.

- Apache-2.0 licensing, scoped companion attribution and a plain-text wordmark.
- Local SQLite/FTS5 retrieval for explicitly approved UTF-8 text and Markdown.
- Immutable revisions, exact source-line citations, source lifecycle and egress controls.
- Bounded context and explicit caller-required evidence.
- Extractive task checkpoints with evidence revalidation on resume.
- CLI, Python library and optional fixed-scope MCP stdio tools.
- Offline accounting and deterministic output checks with unknown usage preserved.
- Clean installed-workflow verification and sanitized historical benchmark evidence.

The proposed same-source retrieval correction was rejected on independent
evidence; runtime behavior remains equal to retained `8318473`.

General answer completeness, semantic retrieval and quality-preserving token/cost
savings are not established. The historical 96-call result, its negative findings
and pending independent human review remain unchanged. Publication remains a separate release gate. See release notes for supported scope.

The standalone local measurement helper now reads the installed package version, reports actual stored chunk counts, and distinguishes its retained exact-single-line hit metric from coverage within larger exact excerpts. Frozen benchmark scores are unchanged.
