# Meridian calibration technical operations manual

Synthetic Meridian/Harbor evaluation document. No real organization, secret or person is represented.

This long manual covers the fictional Meridian training fleet. Sections are independent operational records; headings do not imply that nearby sections share the same approval authority.

## 1. Reference certificate custody

The reference certificate custody procedure applies to the calibration subsystem during a scheduled training maintenance window. Its checklist is recorded under the subsystem revision and the training station identifier; it must not be copied into a production approval record.

Use the documented reference fixture and note its revision. Substituting a convenient spare can alter the result, so a substitution requires a separately reviewed comparison before it is accepted as equivalent.

When an operation stops midway, retain the last completed checkpoint and mark the unfinished step. Do not infer completion from the absence of an alarm. The next operator revalidates the checkpoint before resuming.

Worked example for reference certificate custody: a training operator starts with an incomplete custody entry and an apparently healthy subsystem indicator. The indicator is retained as an observation, but the missing custody entry remains unresolved. The operator records which evidence is missing and pauses the dependent action. A later shift must not copy the healthy indicator into the approval field or claim that the custody problem was repaired by waiting.

Before repeating the reference certificate custody check, identify the previous attempt by its immutable observation reference. State whether the new attempt changes the fixture, operator, software revision, or environment. Preserve both attempts even when the second result is easier to interpret. If only one field changes, describe that field rather than calling the entire attempt equivalent. This trace makes a comparison reviewable without requiring the reader to reconstruct an undocumented history.

For calibration evidence, the review packet contains the original observation, the declared method, the operating conditions, and any known missing interval. The reviewer distinguishes a directly observed result from an interpretation written later. An interpretation may be useful, but it cannot silently become the source observation. If an automated export omits the original units or reference identifier, treat that export as incomplete and request the intact record before relying on it.

The handoff for reference certificate custody states the completed step, its supporting reference, the unresolved dependency and the next proposed action. A proposal is not an execution receipt. The receiving operator checks that the reference is still available and eligible before resuming. When the source was withdrawn, keep the user objective but suppress the withdrawn source-derived conclusion. Do not invent a replacement conclusion solely to make the handoff look complete.

A closure note for the calibration subsystem records who owns the remaining uncertainty and which event would resolve it. A calendar reminder, green display or quiet alarm panel does not resolve missing evidence. The training environment may be reset after the note is preserved, but the reset does not retrospectively change the outcome of the attempt. Use the retained receipt when comparing this exercise with a later one, and identify that comparison as a new review.
