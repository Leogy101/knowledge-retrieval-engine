# Harbor temporary access policy

Synthetic Meridian/Harbor evaluation document. No real organization, secret or person is represented.

A rehearsal operator receives the release-reader role for two hours. The role permits reading release cards and audit events; it cannot publish or delete them.

Only the duty steward can authorize public traffic. A release-reader token cannot substitute for that authorization.

Revoking temporary access prevents later reads but does not erase copies already exported.
