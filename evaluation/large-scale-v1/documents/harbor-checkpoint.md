# Harbor continuation card format

Synthetic Meridian/Harbor evaluation document. No real organization, secret or person is represented.

A continuation card must retain objective, constraints, decisions, unresolved questions, next action, and evidence references. Source-derived assertions depend on those exact references.

On resume, remove an assertion when its supporting reference is revoked or superseded. Preserve unrelated user constraints and mark the affected decision unresolved; do not silently substitute a different decision.

A resume is a reference validation step, not permission to carry out deployment.
