# Meridian operator continuation rules

Synthetic Meridian/Harbor evaluation document. No real organization, secret or person is represented.

Checkpoint fields are objective, constraints, decisions, unresolved questions, next actions and exact evidence references. A quoted-source decision depends on every reference attached to that decision.

Resume validates references against the current corpus. Revoke or supersede one dependency and suppress the dependent source-derived decision, while retaining unrelated user constraints and marking the decision unresolved.

Resuming a checkpoint does not authorize deployment, data export or a permission change. A proposed next action remains a proposal until separately approved.

The source and lifecycle snapshot used for resume must be recorded separately from the older checkpoint snapshot.
